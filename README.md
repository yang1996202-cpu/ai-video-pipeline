# ai-video-pipeline（AI 视频生产管线·编排母 skill）

把"做一条 AI 短剧/概念片/预告片"编排成一条可复用的生产管线。本 skill 是**编排层**，不重写子 skill 的方法论，只负责阶段衔接、台账维护和纪律执行。

## 四阶段编排

| 阶段 | 子 skill | 产出 |
|---|---|---|
| 1. 剧本 | `stc-*`（救猫咪节拍表，7 拍微片）或 `shanyin-writer-2-recon` | 定稿剧本（角色表+场景表+叙事节点） |
| 2. 资产 | `chaoge-assets-trial`（超哥，人物母板）+ ai-film（场景空间底图） | 角色母板（9:16）+ 场景空间底图 + 道具母板 |
| 3. 分镜 | `shanyin-storyboard-2-recon`（山音九列） | 分镜表（每镜景别/机位/运镜/首帧来源/画面描述） |
| 4. 视频 | `pixmax-cli`（Seedance）+ ai-film（16 项合同提示词） | 分段视频 + 合成成片 |

**硬规则**：进入下一阶段前，上一阶段必须定稿（用户确认）。资产未定稿不得进分镜，分镜未定稿不得进视频。

## 五条一致性纪律

1. **资产台账**：每个角色/场景/道具的节点 UUID 记入台账，台账没有的图 = 不存在。
2. **锁脸接力**：R01 文生图定稿后，所有换装/状态图必须 image edit 继承 R01 的脸，绝不用文生图重画第二张脸。
3. **保留原声**：Seedance 原声保留，禁止 sine 合成；纯分镜素材最终统一配乐时静音（零台词短片尤其适用）。
4. **画风锚定**：全片画风锚定句逐字复用；画风从母板定调；提示词过度写"写实渲染"会把 CG 推向真人照片。
5. **场景空间底图**：场景图锁空间/地标/主光方向，不锁构图机位；写成"大全景关键帧"=锁死机位=模型没发挥空间。

## 画布五层平铺拓扑

```
母板(9:16) → 场景空间底图(16:9)+道具(3:4) → 设定板(16:9) → 关键帧(16:9,挂母板+场景) → 视频(挂关键帧+场景图+母板)
```

- **铺节点不花钱，花钱是点生成**：AI 先铺全部节点连好线，用户按依赖顺序点生成；母板先验收画风再点下游。
- 关键帧/视频入参铁律：人物大到能看清脸才挂母板锁脸；大全景/成点镜头人物是色点，不挂母板只写颜色词。
- **视频三层入参 = 关键帧（锁起点画面）+ 场景图（锁空间，防运动背景崩）+ 母板（锁脸，防运动脸漂）**——关键帧首帧只锁"起点构图"，视频是运动的，场景图不能省。

## CLI 技术坑速查

| 坑 | 症状 | 正解 |
|---|---|---|
| 分辨率 | 480P 略糊 | **720P 清晰但贵，480P 省积分**；按积分权衡，更高 SUPER_1080P / SUPER_4K |
| 裸 `canvas node create` | 撞 409 revision | 用 `image generate`（文生图）/ `image edit`（图生图锁脸）高层命令 |
| 多参考连线 | image edit 单参考 | `node create --left <uuid> --left <uuid>` |
| `node delete` 命令 | 仍撞 409 | `canvas batch` delete 字段 + `baseRevision` |
| 换线被拒 | `@ mention node must exist` | 先扫并剥掉 `%%@[节点]...%%` 残留 |
| 改位置/名字不生效 | `-u position.x=` 进错字段 | metaData 是 JSON 字符串，解析原值回写 |
| 子账号 | 看不到画布/权限错 | 画布挂主账号项目，浏览器切主账号 |
| 删节点残留成品图 | defaultAsset 只读 | 删节点重建（delete + create + update） |
