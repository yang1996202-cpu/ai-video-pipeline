# ai-video-pipeline（AI 视频生产管线·编排母 skill）

把"做一条 AI 短剧/概念片/预告片"编排成一条可复用的生产管线。本 skill 是**编排层**，不重写子 skill 的方法论，只负责阶段衔接、台账维护和纪律执行。

> v2（2026-10-20《长命》重构）：视频阶段升级为**组合生成制**——15s 多镜一组 + 音频资产接力 + 生成波次制。

## 编排全链

| 阶段 | 子 skill | 产出 |
|---|---|---|
| 1. 剧本 | stc-*（救猫咪节拍表，7 拍微片）或 shanyin-writer-2-recon | 定稿剧本（角色表+场景表+叙事节点） |
| 2. 资产 | asset-templates（自有模板库 A角色/B设定板/C道具/D场景） | 9:16 母板 + 3:4 道具 + 16:9 场景底图 |
| 3. 分镜 | shanyin-director-1-0（新片五步）/ shanyin-storyboard-2-recon（快速迭代） | 九列分镜表 + **组划分（≤15s/组，回传 STEP4）** |
| 4. 视频 | pixmax-cli 组合生成制 + asset-templates 模板E | 15s 多镜组合视频（音频接力挂线） |
| 5. 合成 | ffmpeg 按分镜表时长 trim + concat | 粗剪 |
| 6. 配音 | ffmpeg 三层音轨 amix（BGM/环境/点音效） | 成片 |

**硬规则**：上一阶段定稿（用户确认）才进下一阶段。

## 组合生成制（v2 核心，2026-10-20《长命》9 组实测）

- **一镜一条已废弃**：旧结论"多分镜脸漂"被 FAST+referToVideo+四段式逐镜切点推翻。31 镜砍到 9 组，成本降 2/3
- **组划分**：同场景+连续叙事 ≤15s；分镜阶段就分好（STEP3 回传）
- **文字首帧占位**：四段式里"第一可见帧已包含…"就是首帧指挥，关键帧图仅口型/回环锚镜需要（31→2）
- **音频资产接力（纪律7）**：ffmpeg 提取上组音频 → 裁 5-6s 短样例 → --asset-type AUDIO 上传 → %%@[节点]%% 引用挂线下游组。环境声/人声跨组一致性在生成端解决
- **生成波次制**：波0资产 → 波1独立组 → 波2接力组。铺完节点先出"生成总计划"（波次表+接力图+音乐切点），AI 在波间自动跑提取流水
- **返修制**：单组翻车单组重跑；口型镜拆单镜节点（挂保留关键帧）精修

## 七条纪律

1. **资产台账**：UUID 全程登记，没进台账的图=不存在
2. **锁脸接力**：衍生状态 image edit 继承基础母板脸；AI 只铺节点，生成由用户点（--run 禁用）
3. **保留原声**：includeAudio=true；音轨统一靠音频接力+后期三层，禁 sine 合成
4. **画风锚定**：全片画风句逐字复用进每个提示词
5. **空间底图**：场景锁空间/地标/主光不锁机位
6. **运镜强制**：每镜一条运镜（组合制下=组内每镜头段落），禁"固定机位+动作极小"默认；固定镜也要画面内运动主体
7. **音频接力**：短样例(5-6s) + --asset-type AUDIO（默认 IMG 会建错节点类型被拒）+ %%@[节点名]%% 引用（纯文字模型分不清）+ update 必带 prompt 全文（整体覆盖语义，不带即清空）

## CLI 坑速查（节选，全表见 SKILL.md）

| 坑 | 正解 |
|---|---|
| node update 不带 --prompt | **清空原 prompt**——update 必带全文 |
| 音频上传默认 IMG | 显式 --asset-type AUDIO |
| image generate 不带 --run | 纯 dry-run 不落画布，铺节点用 node create |
| 网页模型选择器 | 不认节点预设，点生成前必核对下拉 |
| 参考音频超时长 | 裁 5-6s 短样例 |
| project use | 会清空 session token，先备份 |

## 配音混音（STEP 6）

三层轨道：**A. BGM**（一首曲按情绪切段，-9dB）+ **B. 环境**（跨镜连续声音桥，-24~-34dB）+ **C. 点音效**（逐镜打点，-6~-20dB）。

选曲不用耳朵：ffmpeg 解码 8kHz PCM 每 5s 算 RMS 能量曲线，找"低谷→渐强→长强段"。

混音四坑：①-ss/-t 写 -i 前 ②afade 排 adelay 前 ③amix 加 normalize=0 ④每轨 apad 补齐等长。
